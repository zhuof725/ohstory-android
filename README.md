# OH Story · Android

把网文写作工作台做成一个能在安卓上直接装的 App：应用内跑一个本地服务（127.0.0.1:43113），
前端与桌面版共用同一套页面，文稿存在应用私有目录。

## 下载

Actions → 最近一次 `build-apk` → Artifacts → `ohstory-debug-apk` → 解压得到 `app-debug.apk`。

debug 包自带调试签名，可以直接装（设置里允许「安装未知来源应用」）。

## 已实现

- 书架 / 目录 / 编辑器（自动保存、字数）
- 新建长篇或短篇、导入 TXT（按「第X章」拆章）、导出 TXT
- 设定 / 大纲 / 追踪 三个面板直接编辑
- AI：写这章 / 续写 / 去 AI 味 / 审稿 / 润色 / 出细纲（流式）
- 模型配置：接口地址、Key、拉取模型、测试连接

## 暂未实现（桌面版有）

- 原版脚本流程（卷纲/细纲契约、追踪状态机、素材库拆解）——依赖 Python 与 Node 脚本
- 去 AI 味体检（1586 行检测器）
